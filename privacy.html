Privacy Policy

This policy explains how JoyCrew Test accesses, uses, stores and shares Google user data.

Data we access

  • Google account identifier, email address, name and profile image.
  • Your YouTube channel ID, channel title and thumbnail, obtained with the youtube.readonly scope through the YouTube API Services.

How we use the data

  • To identify you and to verify that the YouTube channel you connect belongs to you.
  • To check that videos you register were uploaded to your own channel.

We do not use Google user data for advertising, and we do not sell it.

Storage and sharing

This is a test application. Data is kept only in memory on the test server and is discarded when the server stops. We do not share Google user data with third parties.

YouTube API Services

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access

You can revoke this app's access at any time from your Google account's security settings: https://myaccount.google.com/permissions.
